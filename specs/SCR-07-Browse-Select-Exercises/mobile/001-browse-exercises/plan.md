# Implementation Plan: SCR-07 Browse & Select Exercises

**Branch**: `001-browse-exercises` | **Date**: 2026-09-17 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/SCR-07-Browse-Select-Exercises/mobile/001-browse-exercises/spec.md`

---

## Summary

SCR-07 adds a browsable, searchable exercise catalogue screen to ForgeApp. The screen operates in two modes (browse and picker) sharing the same layout chrome. It extends the existing `exercise` feature — which already has a data layer (`ExerciseRecord`, `ExerciseLocalDataSource`) — by adding the missing domain, application, and presentation layers using ForgeApp's Clean Feature-First Architecture. All data is read synchronously from the seeded Drift `exercises` table; no network call is made. Search debounce and in-memory filtering are handled entirely within the Bloc.

## Technical Context

**Language/Version**: Dart 3.12.x / Flutter latest stable (FVM-managed)

**Primary Dependencies** (all existing — zero new packages):
- `flutter_bloc ^8.0.0` — `ExerciseCatalogueBloc` (Bloc, not Cubit)
- `get_it ^7.6.0` — DI registration for repository, use case, bloc
- `go_router ^13.0.0` — `/plans/exercises` route with `PickerContext?` extra
- `drift` — read the `exercises` table via `AppDatabase`
- `fpdart ^1.1.0` — `Either<AppException, List<Exercise>>` in repository
- `equatable ^2.0.5` — `Exercise` entity, `PickerContext`, Bloc states

**Storage**: `exercises` table (existing). No new tables.

**Testing**: `flutter_test` + manual fakes (implements interface in test) — same pattern as SCR-06 home feature. `bloc_test`/`mocktail` are not in the governed dependency set; see SCR-06 precedent.

**Target Platform**: Android 10+ / iOS 15+; portrait-only; single dark theme.

**Performance Goals**: Full catalogue displayed within 2 seconds of screen entry (SC-001); synchronous in-memory filtering (< 16 ms per keystroke on realistic catalogue size).

**Constraints**:
- No network calls — offline Drift-only
- No new packages (ADR-030)
- Bloc only — no Cubit (ADR-002)
- go_router only — no second router (ADR-003)
- GetIt DI — no alternative (ADR-004)
- Single fixed dark theme — no light mode (ADR-037)

**Scale/Scope**: Single screen, ~20 seeded exercises at POC launch.

## Key Implementation Notes

### Search Debounce (no rxdart)

```dart
on<ExerciseCatalogueSearchChanged>(
  (event, emit) async {
    await Future<void>.delayed(const Duration(milliseconds: 300));
    _applyFilter(emit, query: event.query, activeFilter: _activeFilter);
  },
  transformer: restartable(),
);
```

`restartable()` is from `bloc_concurrency`, a transitive dep of `flutter_bloc` — no new pubspec entry.

### Shimmer Animation

`ExerciseCatalogueScreen` implements `SingleTickerProviderStateMixin`. An `AnimationController(duration: 1.4s, vsync: this)` drives an `AnimatedBuilder` that interpolates a `LinearGradient` stop between `AppColors.cardAlt` and `Color(0xFF35342F)`.

### Browse-Mode Row (FR-014)

`ExerciseListItem` in browse mode is a plain `Container` / `DecoratedBox` — no `InkWell`, no `GestureDetector`. The chevron is `Icon(Icons.chevron_right)` in `AppColors.textDim`.

### Type-Dot Color Assignment (Research Decision 8)

| `ExerciseType` | Dot Color | Token |
|---|---|---|
| `weighted` | `Color(0xFF7DF4FF)` cyan | `AppColors._cyan` (accessed via its hex value; field is private) |
| `timeBased` | `AppColors.lime` | `#C3F400` |
| `bodyweight` | `AppColors.textMuted` | `#C4C9AC` |

Because `AppColors._cyan` is a private field, the exercise type dot will use its literal hex value `const Color(0xFF7DF4FF)` with an inline comment referencing the design spec. This is the sole exception to the "no hardcoded color" rule, justified by the private field access restriction.

### ExerciseType Display Labels

Define as an extension on `ExerciseType` in the presentation layer:

```dart
extension ExerciseTypeLabel on ExerciseType {
  String get displayLabel => switch (this) {
    ExerciseType.weighted   => 'Weighted',
    ExerciseType.timeBased  => 'Time-based',
    ExerciseType.bodyweight => 'Bodyweight',
  };
}
```

### Error String

The error message string `"Couldn't load the exercise catalogue"` matches the spec exactly. It will be emitted by `ExerciseRepositoryImpl` as a `CacheException` message, consistent with the pattern used in the home feature.

### Test Fakes (no mocktail)

class _FakeExerciseRepo implements ExerciseRepository {
  final Either<AppException, List<Exercise>> Function() response;
  _FakeExerciseRepo(this.response);
