# Implementation Plan: SCR-18 Cancel Active Workout Confirmation

**Branch**: `001-scr-18-cancel-workout` | **Date**: 2026-09-23 | **Spec**: [spec.md](spec.md)

## Summary

SCR-18 is a transparent overlay screen at `/workout/cancel` that guards against accidental workout session loss on SCR-16. It presents a destructive confirmation modal ("Keep Going" / "Discard Workout") over the dimmed active workout screen. The implementation is purely additive to the existing `workout_session` feature: one new screen (`CancelWorkoutScreen`, a `StatefulWidget`), two new `ActiveWorkoutBloc` events to fill the pre-designed cancel path in SCR-16, and a real `GoRoute` replacing the SCR-16 stub. No new tables, no new Bloc, no new packages — discard is a navigation-only operation because the in-progress session is in-memory only.

**Target Platform**: iOS + Android (mobile only)

**Project Type**: Flutter mobile app (feature addition)

**Performance Goals**: SCR-18 modal appears without any perceptible delay (FR-001 specifies "immediately")

**Constraints**: Offline-only (no network); Drift is sole persistence layer; single dark theme; `Bloc` only (no `Cubit`); `go_router` only; `GetIt` DI

**Scale/Scope**: 1 new screen file, 2 new events, 2 new bloc handlers, 3 amendment points in SCR-16 files, 4 new AppStrings constants, 1 route update
