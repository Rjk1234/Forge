# Implementation Plan: SCR-21 Workout History Detail

**Branch**: `001-scr-21-workout-history-detail` | **Date**: 2026-09-23 | **Spec**: [spec.md](spec.md)

## Summary

SCR-21 is the Workout History Detail screen — a pushed overlay reached from SCR-20 by tapping a session row. It reads a single completed `WorkoutSession` record from Drift (by sessionId), displays full session detail (hero, three-stat summary, per-exercise cards with type-appropriate set pills), and handles Loading, Success, and Error states. The screen introduces `WorkoutHistoryDetailBloc`, `GetWorkoutHistoryDetailUseCase`, and four new presentation widgets. It is read-only — no Drift writes occur anywhere in the screen's lifecycle.

**Key navigation decision**: SCR-20 passes the `sessionId` (String) as the go_router `extra` when tapping a session row. SCR-21 performs a real `getSessionById` Drift read, giving the Loading skeleton authentic duration and enabling a genuine Error state on failure (see D-01 in research.md).

**Prerequisites**: `WorkoutSessionRepository` and `getSessionById` are already registered and implemented. SCR-20 need not be fully implemented before SCR-21 — the detail route can be added independently under the history branch.

## Technical Context

**Language/Version**: Dart 3.x / Flutter 3.x

**Primary Dependencies**: `flutter_bloc`, `go_router`, `get_it`, `equatable`, `fpdart` (all existing — no new packages)

**Storage**: Drift (existing) — `workout_sessions` table; SCR-21 reads via `WorkoutSessionRepository.getSessionById()` only; no writes

**Testing**: `flutter_test`, `bloc_test`, `mocktail` (all existing)

**Target Platform**: iOS + Android (mobile only)

**Performance Goals**: Loading skeleton appears within one frame of screen push (SC-001); Drift read of a single session completes in < 50ms on device; 20+ exercises render without ANR (SC-006)

**Constraints**: Offline-only (no network); Drift is sole persistence layer; single dark theme (ADR-037); `Bloc` only (no `Cubit`); `go_router` only; `GetIt` DI; no new packages (ADR-030); no `intl` package (pure Dart static arrays for date/time formatting — D-04); read-only (no Drift writes — FR-015)

**Scale/Scope**: 1 new screen, 1 new Bloc (3 files), 1 new use-case, 4 new presentation widgets, 3 amended files (app_strings.dart, app_routes.dart, get_it_setup.dart), 12 new AppStrings constants, 0 new tables
