# Implementation Plan: SCR-19 Workout Summary & Completion

**Branch**: `001-scr-19-workout-summary` | **Date**: 2026-09-23 | **Spec**: [spec.md](spec.md)

## Summary

SCR-19 is the workout completion screen that saves the in-memory session to Drift
and presents the result to the user. It introduces a new `WorkoutSummaryBloc`
(owned by the existing `workout_session` feature) that handles the full save
lifecycle — deduplication check → Drift write → Loading/Success/Error states —
so that the user always has feedback and a recovery path if the local write fails.

The implementation amends `ActiveWorkoutBloc` from the SCR-16 design, removing the
save responsibility (and associated `writeError`, `ActiveWorkoutRetryFinishRequested`,
and `SaveWorkoutSessionUseCase` injection) and replacing `_triggerFinish` with a
simpler `_prepareFinish` that builds the session and emits a navigation flag. No new
tables, no new packages. One new color token (`AppColors.successBg`).

## Technical Context

**Language/Version**: Dart 3.x / Flutter 3.x

**Primary Dependencies**: `flutter_bloc`, `go_router`, `get_it`, `equatable`,
`fpdart` (all existing — no new packages)

**Storage**: Drift (existing) — `workout_sessions` table; all tables
pre-defined; SCR-19 reads (`getSessionById`) and writes (`saveSession`) only

**Testing**: `flutter_test`, `bloc_test`, `mocktail` (all existing)

**Target Platform**: iOS + Android (mobile only)

**Project Type**: Flutter mobile app (feature addition)

**Performance Goals**: Loading state appears within one frame of Finish tap (SC-003);
Drift I/O completes in < 100 ms on device (local write, no network)

**Constraints**: Offline-only (no network); Drift is sole persistence layer; single
dark theme (ADR-037); `Bloc` only (no `Cubit`); `go_router` only; `GetIt` DI;
no new packages (ADR-030)

**Scale/Scope**: 1 new screen, 1 new Bloc (3 files), 2 new presentation widgets,
4 amended files (SCR-16 Bloc state/event/screen + app_routes.dart), 1 new color
token, ~15 new AppStrings constants, 1 DI registration

**Prerequisites**: SCR-16 must be implemented first — SCR-19 depends on
`WorkoutSession.startedAt`, `ActualSet.skipped`, and the SCR-19 `navigateToPostWorkout`
pattern amendments to `ActiveWorkoutBloc`
